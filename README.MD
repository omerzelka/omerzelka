### 🚀 What I'm Currently Focused On

* 🔬 **Hardware & VLSI Design:** Designing custom **RISC-V** core modules and executing full **RTL-to-GDSII** flows using **OpenLane** and **Yosys**.
* 🤖 **Autonomous Systems:** Architecting Unmanned Ground Vehicles (UGV) for **Teknofest** using **ROS 2 Humble**, LiDAR integration, and FSM management.
* ⚙️ **Systems Programming:** Developing multi-process command-line utilities in **C** with **POSIX** standards and low-level memory management.
* 🎮 **Game & Engine Development:** Building multi-directional movement logic and pixel-art rendering using **Godot** and **SFML**.
* 🧠 **AI Integration:** Deploying localized **LLM** runtime environments and working with custom Model Context Protocols (MCP).
